Materiais / Claude Code

Plugins que mudam o jeito de programar com o Claude Code

Plugins somam comandos, skills e regras ao Claude Code. Veja o que eles são, como escolher poucos e bons, e o que conferir antes de instalar qualquer um.

Um plugin é um pacote que acrescenta algo ao Claude Code: comandos novos, skills, agentes ou regras de trabalho. Instalar é simples, e é por isso que dá para exagerar. Cada plugin ocupa um pouco da memória de trabalho do Claude e pode executar código no seu computador.

Como funciona a instalação

O Claude Code tem um comando para plugins, chamado /plugin, e os plugins ficam em catálogos chamados *marketplaces*. Você adiciona um catálogo e escolhe o que instalar. Se preferir, peça ao Claude que faça e explique.

Passo a passo

1

Defina o problema antes

Plugin bom resolve uma dor que você sente. Sem a dor, é só mais um item para carregar.

Pedido 1 · achar o que serve

Quero resolver este problema no meu trabalho com o Claude Code: [descreva]. Sugira até 3 plugins que ajudem, dizendo de onde vêm, o que fazem e qual risco têm. Não instale nada.

2

Audite antes de instalar

Pedido 2 · olhar por dentro

Antes de instalar o plugin [nome], leia os arquivos dele e me diga em português: que comandos ele roda, se acessa a internet, se mexe em arquivos fora do projeto e se pede alguma chave. Aponte qualquer coisa suspeita.

3

Instale um por vez

Instale um, use por uma semana e só então decida se fica. Dois plugins novos de uma vez dificultam saber qual causou um problema.

4

Remova o que não usa

Plugin parado ainda carrega peso. Revise a lista uma vez por mês.

O que conferir

  • Origem conhecida: repositório oficial ou autor com histórico.
  • Atividade recente: foi atualizado há pouco tempo?
  • Permissões: o que ele pode fazer no seu computador?
  • Reversão: existe um jeito simples de desinstalar?

Plugin de terceiros é código de terceiros. Ler antes de instalar leva dois minutos e evita a maior parte dos problemas.
