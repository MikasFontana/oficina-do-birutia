# Aranha que arranca links (curiosidade)

Um projeto de brincadeira leva a expressão "web crawler" ao pé da letra: uma aranha animada anda pela página e arranca os links. Há demonstração no navegador.

Um *web crawler* é um programa que percorre páginas da internet seguindo links. Alguém levou o termo ao pé da letra: o Literal Web Crawler (repositório adampog/literal-web-crawler, licença MIT, conferido no GitHub) mostra uma aranha animada que caminha pela tela, segura links com as patas e os arranca pelo caminho. Não é uma ferramenta de coleta de dados: é um projeto de animação para brincar, chamar atenção e estudar animação feita só com código.

## Como ver

### Demonstração no navegador

Procure a demonstração indicada no README do repositório, no computador. A aranha anda por uma página de referências ou pelo texto que você colar.

### No desktop

O projeto também tem um plugin para o ambiente Omarchy (Linux), em que a aranha anda por uma captura da sua tela, por atalho ou como protetor de tela. Em Windows ou Mac, use a versão do navegador.

## O que estudar nele

O coração é um único arquivo de JavaScript sem dependências, que cuida da direção, do andar com quatro patas e da física dos pedaços arrancados. Serve de material para quem estuda animação com código.

## Pedido para aprender com o código

### Pedido: Entender a animação

```
Leia o arquivo principal deste projeto de animação e explique em português simples como a aranha decide a direção, como as pernas se movem e como os pedaços arrancados caem. Depois sugira um exercício pequeno para eu modificar o comportamento.
```

## Avisos

Os plugins do Omarchy chegam desativados para você ler o código antes; depois de ativados, rodam com as permissões do seu usuário.

A aranha mexe no texto e nos links da página enquanto anda: teste em uma página de teste.

Não confunda com ferramentas que coletam dados de sites: essa é só uma brincadeira.
