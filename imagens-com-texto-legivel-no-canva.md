# Imagens com texto legível no Canva

O Canva Craft, modelo de imagem do próprio Canva, planeja a composição e escreve o texto da arte. Veja como pedir.

Gerar imagem com IA sempre teve um problema: o texto sai torto. O Canva Craft foi apresentado pelo Canva como um modelo de imagem criado pela própria empresa, que primeiro planeja onde cada elemento fica e só depois desenha. O Canva afirma que ele foi treinado com modelos de design como posts, cartazes e cardápios, por isso lida melhor com artes que levam texto.

O acesso e o limite de uso dependem do seu plano. Confira no Canva o que está liberado na sua conta.

## Passo a passo

### 1. Abra o Dream Lab

Ele fica dentro do editor do Canva e também em canva.com/dream-lab.

### 2. Escolha o formato antes

Quadrado para o feed, vertical para stories, horizontal para banner. Escolher antes evita arte cortada.

### 3. Escreva o pedido completo

Coloque entre aspas o texto exato que deve aparecer.

### 4. Peça ajustes pontuais

Mude um detalhe por vez, em vez de refazer a arte.

### 5. Transforme em design editável

Se o Canva oferecer a conversão em camadas, use-a para trocar texto e cor depois.

### 6. Confira letra por letra

Preço, data, telefone e endereço sempre passam pelos seus olhos.

## Pedidos prontos

### Pedido: Post de promoção

```
Post quadrado para Instagram de [tipo de negócio]. Título grande: "[oferta]". Texto menor: "[condição]". Foto de [produto] em destaque, fundo na cor [cor], visual limpo e letras fáceis de ler no celular.
```

### Pedido: Cardápio

```
Cardápio vertical A4 para [nome do local], estilo [rústico, moderno ou minimalista]. Título: "[nome]". Seções: "[seção 1]", "[seção 2]", "[seção 3]". Deixe espaço ao lado de cada item para eu escrever os preços.
```

### Pedido: Stories de evento

```
Arte vertical anunciando "[evento]" no dia "[data]" às "[hora]", em "[local]". Clima [descontraído ou sofisticado], cores [cores], com espaço livre no topo para um adesivo de link.
```

### Pedido: Ajuste pontual

```
Mantenha a arte e altere somente [elemento]: [o que você quer]. O texto "[texto]" deve permanecer exatamente igual.
```

## Avisos

O texto ainda pode sair errado, principalmente letras pequenas. Revise tudo.

Não peça logotipos, personagens ou embalagens de outras marcas.

Se a arte mostra o seu produto, use a foto real dele.

Não inclua nome, telefone ou foto de cliente sem autorização.

## Checklist final

- [ ] Coloquei o texto exato entre aspas
