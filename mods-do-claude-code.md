# O que são mods do Claude Code e três coisas que você pode criar

Um mod muda o comportamento ou a aparência do Claude Code para o seu jeito de trabalhar: um painel que atualiza sozinho, um aviso, um atalho. Veja três usos e como pedir.

Um mod é uma pequena mudança que você acrescenta à interface ou ao comportamento do Claude Code, sem programar na mão. Em vez de ficar repetindo a mesma tarefa, você pede ao Claude para criar o mod, e ele passa a existir ao lado da conversa.

Esse recurso é recente e muda entre versões. Confira na sua versão do aplicativo o nome exato do recurso e onde os mods ficam guardados.

## Três usos que fazem sentido

### 1. Um painel ao lado da conversa

Um painel fixo que mostra o que importa: tarefas do dia, status de um projeto, números de uma campanha. Ele se atualiza enquanto você trabalha.

### Pedido: Pedido 1 · painel

```
Crie um mod que mostre, em um painel ao lado da conversa, a lista de tarefas do arquivo [caminho] e marque as concluídas. O painel deve se atualizar sozinho quando o arquivo mudar.
```

### 2. Um aviso quando algo acontece

Um alerta curto quando uma tarefa longa termina, ou quando o Claude precisa da sua resposta, para você não ficar olhando a tela.

### Pedido: Pedido 2 · aviso

```
Crie um mod que me mostre um aviso quando uma tarefa demorada terminar ou quando você precisar de uma resposta minha. Deve ser discreto e sumir sozinho.
```

### 3. Um atalho para o que você repete

Um comando curto que executa um pedido que você usa sempre, como "resumir o dia" ou "registrar no cofre".

### Pedido: Pedido 3 · atalho

```
Crie um mod com um comando chamado /resumo que leia o que fizemos hoje e escreva um resumo de 5 linhas com o que ficou pendente. Mostre como usá-lo.
```

## Boas práticas

- Um mod, uma função. Mods pequenos são fáceis de entender e de desligar.
- Leia o que ele faz. Peça ao Claude para explicar em português o que o mod executa.
- Desligue o que não usa. Mod esquecido também pesa.
- Teste em uma pasta de teste antes de usar no trabalho real.
Um mod roda no seu computador com as suas permissões. Trate como qualquer programa: crie só o que você entende.
