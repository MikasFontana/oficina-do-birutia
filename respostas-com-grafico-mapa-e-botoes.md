# Respostas com gráfico, mapa e botões

O ChatGPT passou a montar pequenas ferramentas dentro da conversa. Veja como pedir calculadoras, mapas e painéis.

Segundo a referência consultada, a OpenAI liberou em 7 de outubro de 2026 o GPT-6 com um recurso chamado Intelligent UI: em vez de só texto, o ChatGPT pode responder com botões, formulários, gráficos interativos, diagramas, mapas, calculadoras e até jogos. Perguntas simples continuam recebendo texto; quando o assunto pede, a resposta vira uma pequena ferramenta. A liberação é gradual e depende do plano e do aplicativo; confira nas notas de lançamento da OpenAI.

## Passo a passo

### 1. Use a versão web ou um aplicativo atualizado

### 2. Peça o formato com palavras claras

"Crie uma calculadora", "mostre em um gráfico interativo", "monte um mapa", "faça um diagrama clicável".

### 3. Ajuste conversando

Peça para trocar campos, cores, unidades ou incluir um botão. Se preferir menos recursos visuais, há opção para desligá-los nas configurações da versão web.

## Pedidos prontos

### Pedido: Calculadora de meta

```
Crie uma calculadora interativa para eu descobrir quanto preciso guardar por mês para juntar [valor] até [data], com campos para o que já tenho e o rendimento mensal estimado. Mostre o resultado em um gráfico.
```

### Pedido: Comparador de opções

```
Monte uma comparação visual entre [opção A] e [opção B] com estes dados: [dados]. Quero botões para filtrar por preço, benefício e prazo e um resumo de qual vale mais para o meu caso: [caso].
```

### Pedido: Roteiro no mapa

```
Planeje um roteiro de [número] dias em [cidade] e mostre em um mapa as paradas de cada dia, com horário sugerido e uma nota curta sobre cada lugar.
```

### Pedido: Aprender com diagrama

```
Explique [tema] com um diagrama interativo em que eu possa clicar em cada parte para ver a explicação. Depois faça cinco perguntas de múltipla escolha para testar se entendi.
```

### Pedido: Painel de hábitos

```
Monte um painel com os hábitos [lista], em que eu marque o que fiz em cada dia da semana e veja um gráfico do quanto cumpri.
```

## Avisos

Simulações financeiras orientam, mas não decidem: confira os números e, para investimentos, procure um profissional.

Evite colar CPF, dados bancários ou de saúde na conversa.

Se o visual atrapalhar, peça só texto.

## Checklist final

- [ ] Pedi o formato visual desejado
- [ ] Testei os números da ferramenta
- [ ] Sem dados pessoais na conversa
