# Como gastar menos do limite de uso no Claude Code

O limite acaba rápido quando a conversa fica longa, os arquivos são enormes e os pedidos são soltos. Seis hábitos que fazem o mesmo trabalho gastando bem menos.

O limite de uso do Claude Code não depende só de quanto você pede, mas de quanto texto ele precisa carregar a cada resposta. Conversa longa, arquivo grande e instrução repetida pesam. Estes seis hábitos reduzem o consumo sem piorar o resultado.

## Os seis hábitos

### 1. Uma conversa por assunto

Ao trocar de tarefa, comece uma conversa nova (comando /clear). Carregar uma conversa antiga inteira para pedir algo sem relação é o maior desperdício.

### 2. Resuma quando a conversa ficar longa

O comando /compact condensa o que foi feito e libera espaço. Use quando o assunto continua, mas a conversa já está comprida.

### 3. Mantenha o CLAUDE.md curto

O arquivo de regras é lido sempre. Uma página direta funciona melhor que dez. Veja o guia das quatro regras.

### 4. Converta arquivos pesados

PDF e Word gastam mais que texto limpo. Converta para Markdown antes de anexar. Veja o guia do MarkItDown.

### 5. Peça pouco e específico

"Arrume o projeto" faz o Claude ler tudo. "Ajuste a cor do botão na página inicial" faz ele ler uma parte.

### Pedido: Pedido 1 · delimitar o escopo

```
Antes de começar, liste os arquivos que você pretende ler para esta tarefa e me peça confirmação. Leia só o necessário. Tarefa: [descreva].
```

### 6. Rodar tarefas fixas uma vez por semana

Rotinas que não são urgentes, como resumo e organização, podem rodar em horário marcado, e não a cada conversa.

## Plugins ajudam?

Alguns plugins prometem economizar limite, por reduzir respostas longas ou resumir sozinhos. Podem ajudar, mas cada plugin também ocupa espaço. Teste um de cada vez, olhando se o consumo realmente caiu.

## Como medir

### Pedido: Pedido 2 · olhar o consumo

```
Me mostre, em palavras simples, o que mais está pesando nesta conversa: arquivos lidos, instruções fixas e histórico. Sugira o que eu posso cortar sem perder o trabalho.
```

Economizar limite não é pedir menos. É pedir sem repetir o contexto.
